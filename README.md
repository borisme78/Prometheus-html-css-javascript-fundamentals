# Основи HTML, CSS та JavaScript

Мої навчальні вправи з курсу Prometheus / Duke University. Тут я практикую HTML, CSS, JavaScript і роботу із зображеннями.

## Як запускати

Для вебвправ відкриваю `index.html` потрібної папки у браузері. У кожній є `style.css` для оформлення та `script.js` для дій на сторінці. У «Моїх інтересах» JavaScript не потрібний. Встановлювати пакети не треба.

У CodePen переношу вміст `body` без тегів `script` на панель HTML, стилі — на CSS, а JavaScript — на JS. Для фотографій із `assets/` у CodePen потрібні онлайн-адреси зображень.

Файли модуля 2 запускаю окремо в [DukeLearnToProgram](https://www.dukelearntoprogram.com/course1/example/index.php), де доступні SimpleImage, print і навчальні картинки.
