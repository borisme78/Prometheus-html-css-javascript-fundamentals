# Модуль 2

Тут мої вправи з JavaScript. У них я вчуся писати функції, використовувати цикли та змінювати пікселі зображень.

## Файли

- [exercises.js](exercises.js) — робота з рядками, розмірами зображень і значеннями RGB.
- [colored-squares.js](colored-squares.js) — жовтий і пурпуровий квадрати.
- [for-loop-exercises.js](for-loop-exercises.js) — зміна кольорів, прямокутники та градієнт.
- [image-color-exercises.js](image-color-exercises.js) — три кольорові смуги, обмін червоного й зеленого, заміна синього на жовтий.
- [green-screen-and-border.js](green-screen-and-border.js) — зелений екран, чотири кольорові квадрати та чорна рамка.

## Де запускати

Код потрібно виконувати в [DukeLearnToProgram](https://www.dukelearntoprogram.com/course1/example/index.php). Там уже є бібліотека SimpleImage, функція print і потрібні для вправ зображення.

1. Відкрити сайт за посиланням.
2. Відкрити потрібний файл .js і скопіювати його код.
3. Вставити код у поле Code It замість наявного коду.
4. Натиснути Run Code. Результат з’явиться в розділі See It.

Кожен файл запускаю окремо. Щоб перевірити тільки одну вправу, копіюю лише її код разом із потрібними функціями.
