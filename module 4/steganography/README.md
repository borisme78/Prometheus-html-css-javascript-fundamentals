# Стеганографія

У цій вправі я приховую одну картинку в іншій. Відкриваю `index.html` у браузері, вибираю два зображення та натискаю «Приховати зображення».

Картинки обрізаються справа і знизу до спільних ширини та висоти. Оригінали залишаються на перших двох полотнах.

- `crop` створює обрізане зображення.
- `pixchange` і `chop2Hide` очищають молодші чотири біти RGB основної картинки.
- `shift` ділить RGB прихованої картинки на 16 та відкидає дробову частину.
- `newpv` додає значення та повідомляє про помилку, якщо сума перевищує 255.
- `combine` об’єднує підготовлені зображення.

Наприклад, для основного RGB `(100, 150, 200)` та прихованого `(205, 50, 255)` отримую `(96, 144, 192) + (12, 3, 15) = (108, 147, 207)`.

Під результатом бачу розміри до й після обрізання та перевірку RGB одного пікселя. Результат зберігаю кнопкою «Зберегти PNG». Він непрозорий, щоб молодші біти RGB зберігалися точно.

Усі функції є у `script.js`, додаткові бібліотеки не потрібні. Це браузерна версія вправи на Canvas. Для CodePen переношу вміст `body` без тега `script`, CSS та JavaScript на відповідні панелі.
