# Модуль 4

Мій мініпроєкт — сторінка з фільтрами зображень.

Тут є п’ять фільтрів:

- Відтінки сірого.
- Червоний.
- Футбольні смуги — мій власний фільтр із зеленими смугами та білою лінією посередині.
- Веселка — сім горизонтальних кольорових смуг.
- Розмиття — випадкова заміна частини пікселів сусідніми в межах 10 пікселів.

У власному фільтрі знаходжу середнє RGB. Червоний роблю 45% від середнього, синій — 30%, а до зеленого додаю 50 або 20 залежно від смуги, максимум 255. Посередині малюю білу лінію. Наприклад, піксель `(100, 100, 100)` стає `(45, 150, 30)` у світлій смузі, `(45, 120, 30)` у темній або `(255, 255, 255)` на центральній лінії.

Для запуску відкриваю `index.html` у браузері, вибираю зображення та натискаю кнопку фільтра. «Повернути оригінал» скидає зміни. Кожен фільтр працює з копією початкового зображення. При повторному розмитті випадковий результат може відрізнятися.

У CodePen переношу вміст `body` без тега `script` на панель HTML, `style.css` — на CSS, а `script.js` — на JavaScript. Додаткові бібліотеки не потрібні.
